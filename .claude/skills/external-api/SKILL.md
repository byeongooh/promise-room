# 외부 API 붙이기

ODsay를 붙이면서 크게 데인 뒤에 굳어진 방식이다. 이걸 안 지켰다면
"안양→잠실 11분"(실제 62분)을 그대로 배포했을 것이다.

## 1. 키는 서버에만 둔다

브라우저나 앱에서 외부 API를 직접 부르지 않는다. 키가 노출되고 남이
우리 쿼터를 대신 써버린다. 앱 파일도 뜯어보면 안에 박힌 문자열이 나온다.

```
[브라우저 / RN 앱]  →  [우리 서버 API]  →  [외부 서비스]
                            ↑
                        키는 여기만
```

- 라우트는 `withCaller`로 감싼다(`lib/api-guard.ts`). 로그인한 사람만 부를 수 있다.
- 키 이름은 `process.env.*`로만 읽고 응답에 절대 싣지 않는다.
- 이 구조 덕분에 나중에 RN 앱이 같은 API를 그대로 쓴다.

## 2. 응답 구조를 추측하지 않는다 — 실제로 불러 본다

문서만 보고 파싱을 쓰면 조용히 틀린다. 반드시 실제 키로 한 번 호출해
필드 이름과 값을 눈으로 확인한 뒤 코드를 쓴다.

```bash
node --env-file=.env.local -e "…실제 호출해서 응답 구조 출력…"
```

**실제로 겪은 것:** ODsay는 같은 API인데도 도시 안 검색과 도시 간 검색의
필드 이름이 다르다. 요금 `payment` ↔ `totalPayment`, 환승
`bus/subwayTransitCount` ↔ `transitCount`, 경로 종류 `pathType` 1~3 ↔ 11~13.
문서에는 이 차이가 없었다. 요금이 0원, 환승이 0회로 나오고 있었다.

## 3. 숫자가 말이 되는지 본다

응답을 받았다고 끝이 아니다. **아는 사실과 대조한다.**

- 서울→부산이 65분? → 비행기였다(김포→김해). 공항까지 가는 시간이 없다.
- 안양→잠실이 11분? → 잠실에 가지도 않는 경로였다(안양→영등포).

특히 **거리·시간 비율**로 걸러지지 않는 경우가 있다. 안양→서울역 경로는
이동 거리가 직선거리의 1.21배라 어떤 문턱값도 통과한다. 목적지 방향이
아닌데도. 그래서 값 하나로 거르려 하지 말고 **애초에 부르는 조건을 나눈다.**

## 4. 실패는 오류가 아니라 없음으로 내린다

여러 곳을 부를 때 한쪽이 죽어도 나머지는 보여줘야 한다.

```ts
async function orNull<T>(label: string, run: () => Promise<T>): Promise<T | null> {
  try { return await run(); }
  catch (err) { console.warn(`[…] ${label} 사용할 수 없음:`, (err as Error).message); return null; }
}
```

키가 아직 없을 때도 앱이 그대로 돌아가야 한다. ODsay 키를 넣기 전에도
자동차 소요시간은 나오고 대중교통 줄만 빠졌다.

## 5. 점검 스크립트를 남긴다

`scripts/check-odsay.mjs`처럼, 나중에 다시 확인할 수 있는 스크립트를 만든다.

- 실제로 겪었던 함정을 **사례로 넣는다.** check-odsay는 성수→강남(도시 안),
  안양→롯데월드(경계 넘음), 서울→부산·대전(도시 간)을 검사한다.
  안양 사례는 버그를 겪고 나서 추가한 것이다.
- **키를 찍지 않는다.** 앞 4글자만 보여준다. 결과를 그대로 공유해도 안전하게.
- 앱과 **같은 판단 로직**을 쓴다. 스크립트만 통과하고 앱은 틀리면 의미가 없다.

## 6. 가입·키 발급은 사람이 한다

Claude는 계정을 만들 수 없다. 사용자에게 안내할 때:

- 어디서 무엇을 골라야 하는지 화면 순서대로 알려준다.
- **키를 채팅에 붙여넣지 말라고 반드시 말한다.** 대화 기록에 남는다.
- `.env.local`과 Vercel **두 곳** 모두에 넣어야 하고, Vercel은 재배포까지 해야
  적용된다는 점을 빠뜨리지 않는다.

## 한국에서 길찾기를 고를 때

구글 길찾기는 한국에서 쓸 수 없다(지도 데이터 반출 규제).

| | 자동차 | 대중교통 |
|---|---|---|
| 카카오모빌리티 | ✅ 하루 1만 건 무료 | ❌ API 없음 |
| 네이버 클라우드 | ✅ | ❌ 자동차만 |
| ODsay | ❌ | ✅ 하루 1천 건 무료 |
| TMAP | ✅ | ✅ (대중교통은 비쌈) |

- 자동차: 카카오모빌리티. `KAKAO_CLIENT_ID`가 곧 REST 키라 별도 발급이 없다.
- 대중교통: ODsay. **Server 방식으로 등록하면 안 된다** — 공인 IP 고정을
  요구하는데 Vercel은 요청마다 IP가 다르다(고정 IP는 월 $100, Pro 이상).
  **URI 방식**으로 등록하고 서버가 `Referer`를 직접 붙여 보낸다.
